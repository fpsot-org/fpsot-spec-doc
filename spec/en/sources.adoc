= Outside sources
include::_fpsot-terms.adoc[]

Specifications build on standards from other bodies, such as the W3C, {abbr-iso-first} and governments.

[[DOC-025]]
*DOC-025.* A specification MUST summarise an outside standard in its own words, and MUST NOT copy its text.
Each citation MUST give the exact version and date, a link, and an archived copy.
Several licences forbid copying, and {abbr-iso} standards are under copyright.
The archived copy keeps the citation useful when a link breaks.

To check a source, read the live page first and note the version it states.
Then save a fresh archived copy and record its address.
