= Pages
include::_fpsot-terms.adoc[]

[[DOC-010]]
*DOC-010.* Each guide page MUST declare one page type in a `:page-type:` attribute.
The type MUST be `tutorial`, `how-to`, `reference` or `explanation`.
These are the four types of the link:https://diataxis.fr/[Diátaxis] model.
A page with one purpose is easier to write and to find.

[[DOC-011]]
*DOC-011.* A repository MUST keep its normative text in `spec/en/` and `spec/fr/`.
It MUST keep its guides in the Antora folder layout, under `docs/modules/en/` and `docs/modules/fr/`.
A page MUST have the same file name in both languages.
The website then collects every specification the same way.

[[DOC-030]]
*DOC-030.* Authors MUST draw each diagram as code, such as PlantUML.
Every image MUST have a text alternative.
Reviewers can then read and change a diagram like text.
A text alternative lets people who cannot see the image get the same information.

[[DOC-040]]
*DOC-040.* An abbreviation MUST render as a {abbr-html-first} `abbr` element that links to the glossary.
The writing specification sets how to write it.
Screen readers and the pointer then give the full form on any page.
Inside the text of a citation link and in a References entry, an abbreviation is plain text instead.
DOC-043 and DOC-044 set these.

[[DOC-046]]
*DOC-046.* Each code block MUST name its language, such as `[source,json]`.
A block of plain output or prose MUST use `text`.
The site colors code by language, so readers tell its parts apart faster.
Tools that read the source also know how to parse each block.
