= FPSOT documentation specification

This specification sets how FPSOT specifications are documented, organized and published.
Its rules have been normative since version 0.1.0, and `CHANGELOG.md` lists the changes in each version.

== Implement this spec

Read the normative text in `spec/en/` or `spec/fr/`.
Each requirement has an ID, such as `DOC-001`.

== Adopt this spec

Read the guides in `docs/modules/en/pages/` or `docs/modules/fr/pages/`.

== Jurisdiction model

`model/jurisdiction.yaml` is the LinkML model of the comparison data that every FPSOT specification keeps in `jurisdictions/`.
`model/examples/` holds valid and invalid examples, and `model/test-model.sh` checks them.
