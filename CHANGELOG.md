# Changelog

All notable changes to this specification are listed here.
The format follows [Keep a Changelog 1.1.0](https://keepachangelog.com/en/1.1.0/),
and versions follow [Semantic Versioning 2.0.0](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

## [0.3.1] - 2026-11-09

No rule changes.

### Changed

- French guide « Ajouter une collectivité publique »: « demande de fusion » replaces « demande de tirage » for pull request, as in the term base.

## [0.3.0] - 2026-11-08

### Added

- DOC-047: each published output states its copyright holder and license; a PDF has a notice page after its title page, and each HTML spec page shows it apart from the website's own license.

## [0.2.1] - 2026-11-07

### Fixed

- README: it no longer calls the specification a draft; its rules have been normative since version 0.1.0.

## [0.2.0] - 2026-11-04

### Added

- DOC-043: a page that names an outside standard links that name to the standard itself.
- DOC-044: each page that cites outside sources ends with a References section, right before its document history. Entries are normative or informative, with title, version, date, link and archived copy. The citation details of DOC-025 move here.
- DOC-045: in HTML, a link that leaves the site shows an external-link marker that screen readers announce, and opens in the same tab.
- DOC-046: each code block names its language.

### Changed

- DOC-025 keeps the rule against copying an outside standard; DOC-044 now sets what a citation gives.
- DOC-040: an abbreviation inside a citation link's text is plain text.
- English text uses US spelling, as the writing specification now requires.

### Fixed

- DOC-042, Canada row: a fresh archived copy of the federal direction on ICT accessibility; the earlier copy no longer opens.

## [0.1.1] - 2026-11-03

### Fixed

- DOC-020: the regional bloc level is optional (MAY), since the comparison data has no bloc yet.
- DOC-025: a citation gives the version and the date that the publisher states. Many sources state only one, or neither.

## [0.1.0] - 2026-11-02

### Added

- Repository files DOC-001 to DOC-003.
- Page rules DOC-010, DOC-011, DOC-030 and DOC-040.
- Organisation by jurisdiction DOC-020 to DOC-026, and the jurisdiction LinkML model.
- Version rules DOC-031 to DOC-033 and output rules DOC-041 and DOC-042.
- Comparison with Canada and Québec.
